Preview

NTmart POS for Windows

Phase 1: sign-in and catalogue browsing. Runs on your existing NTmart MySQL/MariaDB database.

Request the preview

What you need

  • A Windows PC
  • Network access to your NTmart MySQL or MariaDB server
  • An existing NTmart user account

Preview build. It has no licence enforcement yet and isn't for distribution to client shops. Try it on a copy of your database first.

Install in three steps

Run the app

Copy NTmartPOS.exe to the PC and double-click it.

Enter your database

Fill in the server, user and database name. The defaults are localhost:3306, root and ntmart.

Sign in

Use your NTmart username and password. Change servers later with Database… on the sign-in screen.

Building from source?

Developers can build the app with PowerShell from the NTmart POS source:

.\build.ps1
.\NTmartPOS.exe
