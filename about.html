About

Making NTmart faster, without starting over

Why we're rebuilding NTmart POS as a native Windows app.

Our story

From the browser to the desktop

NTmart POS started as a PHP application. It works, but it needs a web server and a browser on every till, and it can feel slow at the counter.

The Go edition keeps everything that matters, your data, users and settings, and replaces the front end with a fast native Windows app.

Because it uses the same database, nobody has to migrate anything. Shops can keep working while each module moves over.
