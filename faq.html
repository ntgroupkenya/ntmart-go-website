FAQ

Frequently asked questions

Can't find your answer? Ask us.

General

What is NTmart POS Go edition?

It's a native Windows rewrite of NTmart POS, written in Go. It runs on the same database as the current PHP version, so both can be used side by side while modules move over.

Is it ready to replace the PHP edition?

Not yet. The Go edition is a preview (Phase 1). It covers signing in and browsing the catalogue. Keep using the PHP edition for everything else until those modules move over.

Can I use both editions at the same time?

Yes. That's the point of the design. Both connect to the same MySQL/MariaDB database, so changes made in one are visible in the other.

Installation

What do I need to run it?

A Windows PC that can reach your NTmart MySQL or MariaDB server, either on the same machine or over your local network.

How do I install it?

Copy NTmartPOS.exe to the PC and run it. On first run it asks for your database server details. See the download page for the full steps.

Database

Which database settings does it use?

The default is server localhost:3306, user root and database ntmart. You can change them on first run.

Where are the connection settings saved?

In %APPDATA%\NTmartGo\config.json for each Windows user. To change them later, click Database… on the sign-in screen.

Is it safe to try on my live shop database?

While the Go edition is in preview, we recommend trying it on a copy of your database first. Use Database… on the sign-in screen to point it at the copy.

Accounts

Do I need new user accounts?

No. Sign in with any existing NTmart user account.

I forgot my password. What do I do?

Passwords are shared with the PHP edition. Ask your NTmart administrator to reset it there, or contact support.

Licensing and pricing

Can I give the preview to my clients?

Not yet. The preview has no licence enforcement, so it isn't for distribution to client shops. Licensing is on the roadmap.

How is it priced?

Per till, billed monthly or yearly. See pricing for the plans.
