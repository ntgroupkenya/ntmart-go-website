Native app

A real Windows program

NTmart POS Go edition is written in Go and uses native Windows controls. You get one executable with nothing else to install on the till.

  • Starts in seconds, even on older PCs
  • No browser, local web server or PHP runtime needed on the till
  • Familiar Windows keyboard shortcuts and dialogs
NTmartPOS.exe
Opens straight to sign-in
Native Win32 windows
Same database

No migration day

The Go edition connects to your existing NTmart MySQL or MariaDB database. Both editions read and write the same tables, so you can use them side by side.

  • Works with MySQL and MariaDB
  • Connect to a server on the same PC or over your network
  • Keep using the PHP edition for modules that haven't moved yet
Server: localhost:3306
User: root
Database: ntmart
User accounts

Sign in like you always have

Cashiers and managers sign in with their existing NTmart usernames and passwords. There's nothing to set up again.

  • Uses the user accounts already in your NTmart database
  • Sign out at the end of a shift and hand over the till

Settings

Change servers in a click

Connection details are saved for each Windows user in %APPDATA%\NTmartGo\config.json. Use Database… on the sign-in screen to point the app at a different server, such as a test copy.
