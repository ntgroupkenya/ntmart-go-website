Welcome

NTmart POS Go is a rewrite of NTmart POS as a native Windows app. It runs on the same MySQL/MariaDB database you already have, so nothing moves and nothing gets lost.

The Go edition reads and writes the existing NTmart tables exactly as the PHP edition does. Shops can move over one screen at a time, with both editions running at once on the same data.

Read the getting started guide »

At a glance

  • Windows desktop app
  • MySQL / MariaDB
  • Uses your existing NTmart users
  • ESC/POS thermal receipts
  • Built with Go

Why the Go edition?

  • No data migration. Your products, clients, sales and accounts are already where the Go app looks for them.
  • Side by side with PHP. Use Go for the finished screens and PHP for the rest, on the same data, at the same time.
  • Checked against PHP. Each module runs the same actions as PHP and compares the rows written. VAT matches to six decimal places and receipts match byte for byte.
  • Exact money. Every amount and quantity uses exact decimals. Multi-step writes run in one transaction and are safe to retry.

Frequently asked questions

Do I need to move my data?

No. The Go edition connects to the MySQL/MariaDB database NTmart already uses and works with the same tables.

Can I keep using the PHP edition?

Yes. Both editions can run at the same time on the same database. Use the Go app for the screens that are ready and PHP for everything else.

Can shops use it in production yet?

Not yet. The Go edition is a preview until Phase 8 (licensing, installer and self-update) is finished. Until then it is for testing alongside the PHP edition.

How do you know the numbers are right?

Each module is checked against the PHP edition: the same action runs through both and the rows they write are compared. Totals and VAT match to six decimal places, receipts are byte-identical, and every client statement closes on its balance.

What do I need to run it?

A Windows PC and access to your NTmart MySQL/MariaDB server. On first run the app asks for the server details and saves them for next time.

Does it support KRA eTIMS and M-Pesa?

Sales are already queued for eTIMS, and the PHP edition sends them for now. The live eTIMS send and M-Pesa STK push are part of Phase 7.
