Why the Go edition

Built for the shop counter

A desktop app that opens instantly and talks straight to your database, with no browser and no local web server.

Native Windows app

Real Windows controls and one small executable. It starts fast and feels at home on the till PC.

Your existing database

It reads the same MySQL/MariaDB tables as the PHP edition, so your products, users and settings are already there.

Side by side

Run both editions together while modules move over. There's no big-bang switch and no retraining day.

Getting started

Up and running in three steps

Install

Copy NTmartPOS.exe onto the Windows PC next to your NTmart server, or any PC on the same network.

Connect

On first run, enter your database server. The default is localhost:3306 with the ntmart database.

Sign in

Use any existing NTmart user account. No new passwords and no new user setup.

One database, two apps

Move over at your own pace

Both editions work on the same data, so changes made in one show up in the other straight away.

  • No export, import or migration step
  • Change the database server any time from the sign-in screen
  • Connection settings are saved per Windows user
